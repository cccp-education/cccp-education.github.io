Catalogue des Plugins

12 June 2026

Catalogue des Briques OSS

Tous les plugins sont sous licence Apache 2.0, groupId education.cccp. Chaque plugin se clone et se consomme en deux commandes :

cd <plugin>/ && ./gradlew publishToMavenLocal
cd .. && ./gradlew <tache>

Consommer un plugin

Chaque plugin est concu pour etre utilise independamment. Exemple avec bakery-gradle :

git clone https://github.com/cccp-education/bakery-gradle
cd bakery-gradle/bakery-plugin && ./gradlew publishToMavenLocal
cd .. && ./gradlew publishSite

Deux commandes. Zero configuration externe. Le fichier site.yml (gitignore) est le seul a remplir, un exemple est fourni.
