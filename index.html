cccp.education

Créateur de Contenus Commun Prolétaire. Briques logicielles libres pour créer du contenu — sites, slides, PDF, videos, documentation — autour de l'ecosysteme AsciiDoc, Gradle et Kotlin.

Des plugins Gradle Apache 2.0 que vous assemblez comme vous voulez. Pour formateurs, enseignants, developpeurs, createurs de contenu.

Decouvrir les plugins A propos

Briques OSS

planner-gradle

Generation de scenarios pedagogiques structures assistee par LLM.

codex-gradle

Pipeline documentaire : Asciidoctor→PDF, slides, RAG pgvector.

codebase-gradle

RAG socle pgvector partage, anonymisation, vibecoding.

slider-gradle

Presentations Reveal.js AsciiDoc→HTML. Pipeline RAG IA, 10 langues.

capsule-gradle

Capture video capsule. Reveal.js + Playwright + TTS.

bakery-gradle

Sites statiques JBake + deploiement gh-pages.

hyperframes-gradle

Pipeline AsciiDoc→MP4 via HyperFrames.

document-gradle

Creation et publication documentaire multi-format (HTML, PDF, EPUB, DocBook).

readme-gradle

Generation de README avec diagrammes PlantUML.

plantuml-gradle

Generation de diagrammes PlantUML via LLM (7 providers, RAG pgvector).

graphify-gradle

Extraction du graphe de connaissance du workspace → graph.json.

api-key-pool-gradle

Pool de cles API LLM avec rotation, tracking quotas, journalisation audit.

workspace-bom

Bill of Materials multi-module. Contrats partages cross-plugin.

runner-gradle

Orchestration, provisioning CLI, deploiement gh-pages.

agile-gradle

Pilotage agile assiste par IA. 7 ateliers de cadrage + backlog + sprints.

ticket-gradle

Creation et suivi de tickets GitHub. Backlog→Issues, Kanban board.

review-gradle

Code review assistee par IA. Analyse PR, score qualite, quality gates.

flow-gradle

Orchestration merge/close/CI. Merge quand gates OK, auto-close tickets.

workspace-agent

Plugin JetBrains Platform. 5 dashboards IA + actions menu contextuel.

Comment ca marche

Infrastructure

workspace-bom, graphify-gradle, api-key-pool-gradle, codebase-gradle. Le socle : contrats partages, graphe de connaissance, pool de cles LLM, RAG pgvector.

Briques metier

planner, codex, slider, capsule, bakery, plantuml, readme, document, hyperframes. Les transformateurs : chaque brique fait une chose, vous les combinez.

Orchestration

runner-gradle, agile-gradle, ticket-gradle, review-gradle, flow-gradle. Pilotage, deploiement, CI/CD.
