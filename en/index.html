cccp.education

Common Content Creator Proletarian. Free software bricks to create content — sites, slides, PDFs, videos, documentation — around the AsciiDoc, Gradle and Kotlin ecosystem.

Apache 2.0 Gradle plugins you assemble however you want. For trainers, teachers, developers, content creators.

How it works

Infrastructure

workspace-bom, graphify-gradle, api-key-pool-gradle, codebase-gradle. Le socle : contrats partages, graphe de connaissance, pool de cles LLM, RAG pgvector.

Business bricks

planner, codex, slider, capsule, bakery, plantuml, readme, document, hyperframes. The transformers: each brick does one thing, you combine them.

Orchestration

runner-gradle, agile-gradle, ticket-gradle, review-gradle, flow-gradle. Pilotage, deploiement, CI/CD.
